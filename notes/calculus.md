# Calculus — Core Concepts

## Limits
A limit describes the value a function approaches as the input approaches a point.

**Notation:** lim(x→a) f(x) = L

**Example:** lim(x→2) x² = 4

## Derivatives
A derivative measures the rate of change of a function.

**Definition:** f'(x) = lim(h→0) [f(x+h) - f(x)] / h

**Common Rules:**
- Power rule: d/dx [xⁿ] = n·xⁿ⁻¹
- Product rule: d/dx [f·g] = f'g + fg'
- Chain rule: d/dx [f(g(x))] = f'(g(x)) · g'(x)

**Example:** f(x) = x³ → f'(x) = 3x²

## Integrals
Integration is the reverse of differentiation (anti-derivative).

**Notation:** ∫ f(x) dx

**Fundamental Theorem of Calculus:**
∫(a to b) f(x) dx = F(b) - F(a), where F'(x) = f(x)

**Example:** ∫ x² dx = x³/3 + C

## Applications
- Finding max/min values (set derivative = 0)
- Calculating area under a curve
- Velocity from position: v(t) = s'(t)
- Acceleration from velocity: a(t) = v'(t)
